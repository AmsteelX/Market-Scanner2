# Market Signal Scanner — หุ้นสหรัฐ (เทรดสั้น)

สแกนหุ้นสหรัฐทั้ง S&P 500 + Nasdaq-100 ทุกวันหลังตลาดปิด แล้วคัดออกมาเฉพาะตัวที่เข้าเงื่อนไข
6 รูปแบบ (ฝั่งซื้อ 3 + ฝั่งขายชอร์ต 3) สำหรับการเทรดสั้น 1–10 วัน
พร้อมจุดเข้า จุดตัดขาดทุน เป้าหมาย และขนาดไม้ที่คำนวณให้แล้ว
**กรองหุ้นที่ใกล้วันประกาศงบออกให้อัตโนมัติ** และ**เทียบกับราคานอกเวลาทำการ** (pre-market / after-hours)

> เครื่องมือ**คัดกรอง**เท่านั้น ไม่ใช่คำแนะนำการลงทุน — ใช้ย่นเวลาจากหุ้น 600 ตัวเหลือ 20 ตัวไปดูกราฟต่อ

## เริ่มใช้ใน 2 นาที

```bash
pip install -r requirements.txt
python scanner.py
```

ได้ผลลัพธ์ 2 ไฟล์ในโฟลเดอร์ `reports/`

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `latest.html` | เปิดในเบราว์เซอร์ — ตารางสรุปพร้อมสภาพตลาด (ดูบนมือถือได้) |
| `signals_YYYY-MM-DD.csv` | เอาไปเปิด Excel / ต่อยอดเองได้ |

### ตัวเลือกที่ใช้บ่อย

```bash
python scanner.py --account 5000 --risk 0.5     # พอร์ต $5,000 เสี่ยง 0.5% ต่อไม้
python scanner.py --sides long                  # ฝั่งซื้ออย่างเดียว (short ก็ได้)
python scanner.py --earnings flag               # ไม่ตัดหุ้นใกล้วันงบ แค่ติดป้ายเตือน
python scanner.py --gap-alert 5                 # เตือนเมื่อราคานอกเวลาขยับเกิน 5% (ค่าเริ่มต้น 3)
python scanner.py --extended off                # ไม่ต้องดึงราคานอกเวลา (เร็วขึ้น)
python scanner.py --earnings-days 10            # ขยาย blackout เป็น 10 วันก่อนงบ
python scanner.py --universe nasdaq100          # สแกนเฉพาะ Nasdaq-100 (เร็วกว่า)
python scanner.py --tickers NVDA,TSLA,AMD,PLTR  # เช็กเฉพาะหุ้นที่สนใจ
python scanner.py --top 30                      # แสดง 30 ตัวต่อสัญญาณ
python scanner.py --min-dollar-vol 50e6         # เอาเฉพาะหุ้นสภาพคล่องสูงมาก
```

## สัญญาณ 6 แบบที่สแกน

### ▲ ฝั่งซื้อ (Long)

### A · Breakout — ทะลุแนวต้าน 20 วัน
หุ้นที่ปิดที่/เหนือจุดสูงสุด 20 วันพร้อมวอลุ่มหนุน และเทรนด์เรียงตัวถูกทาง

| เงื่อนไข | ค่าที่ต้องผ่าน | ทำไม |
|---|---|---|
| ราคาปิด | ≥ 99.5% ของ high 20 วัน | อยู่ที่จุดทะลุจริง ไม่ใช่ไล่ตามทีหลัง |
| เทรนด์ | ปิด > EMA20 > EMA50 และเหนือ SMA200 | เส้นเรียงตัวถูกทาง ไม่สวนเทรนด์ใหญ่ |
| วอลุ่ม | RVOL ≥ 1.3 เท่า | ต้องมีคนตามซื้อจริง ไม่ใช่ทะลุแบบเงียบ ๆ |
| ADX(14) | ≥ 20 | มีเทรนด์จริง ไม่ใช่แกว่งไปมา |
| ปิดในแท่ง | ≥ 50% ของช่วงวัน | ปิดแข็ง ไม่โดนขายกลับ |

### B · Volume Spike — วอลุ่มพุ่งผิดปกติ
วอลุ่มมักมาก่อนราคา — สัญญาณนี้จับ "มีคนรู้อะไรบางอย่าง" ในวันแรก ๆ

| เงื่อนไข | ค่าที่ต้องผ่าน |
|---|---|
| RVOL | ≥ 2 เท่าของค่าเฉลี่ย 20 วัน |
| ราคาวันนี้ | +1% ขึ้นไป และปิดในครึ่งบนของแท่ง (≥ 60%) |
| มูลค่าซื้อขายวันนี้ | ≥ 30 ล้านดอลลาร์ |
| เทรนด์ | ยังอยู่เหนือ EMA50 |

> วอลุ่มพุ่งส่วนใหญ่คือ**วันประกาศงบ** — ตัวกรองวันงบ (ดูหัวข้อถัดไป) จัดการให้แล้ว

### C · Pullback — ย่อในขาขึ้น (mean reversion)
หุ้นแข็งที่ย่อลึกชั่วคราว เล่นเด้งกลับ ไม่ใช่รับมีดหุ้นขาลง

| เงื่อนไข | ค่าที่ต้องผ่าน | ทำไม |
|---|---|---|
| เทรนด์ใหญ่ | ยังเหนือ SMA200 | ย่อในขาขึ้น ไม่ใช่หุ้นพัง |
| ห่างจาก high 52 สัปดาห์ | ≤ 30% | ไม่ได้ร่วงมาไกลจนโครงสร้างเสีย |
| ภาวะขายมากเกิน | RSI(14) ≤ 38 **หรือ** %B ≤ 0.10 | ย่อลึกพอจะเด้ง |
| 5 วันล่าสุด | ติดลบ | กำลังย่ออยู่จริง |

### ▼ ฝั่งขายชอร์ต (Short)

สามแบบนี้คือภาพกลับด้านของฝั่งซื้อพอดี — เงื่อนไขเดียวกันแต่พลิกทิศ

### D · Breakdown — หลุดแนวรับ 20 วัน
| เงื่อนไข | ค่าที่ต้องผ่าน |
|---|---|
| ราคาปิด | ≤ 100.5% ของ low 20 วัน |
| เทรนด์ | ปิด < EMA20 < EMA50 และ**ใต้** SMA200 |
| วอลุ่ม | RVOL ≥ 1.3 เท่า |
| ADX(14) | ≥ 20 |
| ปิดในแท่ง | ≤ 50% ของช่วงวัน (ปิดใกล้ก้นแท่ง) |

### E · Distribution — วอลุ่มพุ่ง ปิดอ่อน
| เงื่อนไข | ค่าที่ต้องผ่าน |
|---|---|
| RVOL | ≥ 2 เท่า |
| ราคาวันนี้ | −1% ลงไป และปิดในครึ่งล่างของแท่ง (≤ 40%) |
| มูลค่าซื้อขายวันนี้ | ≥ 30 ล้านดอลลาร์ |
| เทรนด์ | ใต้ EMA50 |

### F · Rally Fade — เด้งจนซื้อมากเกินในขาลง
ชอร์ตตอนเด้ง ไม่ใช่ไล่ชอร์ตตอนราคาร่วงไปแล้ว

| เงื่อนไข | ค่าที่ต้องผ่าน | ทำไม |
|---|---|---|
| เทรนด์ใหญ่ | ใต้ SMA200 | หุ้นอ่อนแอจริง ไม่ใช่ขาขึ้นที่แค่พัก |
| ห่างจาก low 52 สัปดาห์ | ≤ 30% | ยังไม่ได้ฟื้นตัวจริง |
| ภาวะซื้อมากเกิน | RSI(14) ≥ 62 **หรือ** %B ≥ 0.90 | เด้งมาพอให้ชอร์ตได้ราคาดี |
| 5 วันล่าสุด | เป็นบวก | กำลังเด้งอยู่จริง |

> ⚠️ **การชอร์ตเสี่ยงกว่าฝั่งซื้อมาก** — ต้องมีบัญชี margin, หุ้นต้องมีให้ยืม (บางตัวยืมไม่ได้
> หรือค่ายืมแพงมาก), ขาดทุนไม่มีเพดาน, และการบีบชอร์ตเกิดเร็วมาก
> สคริปต์ไม่ได้เช็กสถานะการยืมหุ้นให้ ต้องดูในโบรกเกอร์เอง
> ถ้ายังไม่เคยชอร์ตมาก่อน แนะนำให้รัน `--sides long` ไปก่อน

## ตัวกรองวันประกาศงบ

หุ้นที่วอลุ่มพุ่งผิดปกติส่วนใหญ่คือหุ้นที่กำลังจะประกาศงบหรือเพิ่งประกาศไป
การถือข้ามคืนช่วงงบคือการเดิมพันกับ gap ที่**จุดตัดขาดทุนคุมไม่ได้เลย** —
ตั้ง stop ไว้ −3% แต่ตื่นมาเปิด −15% เกิดขึ้นบ่อยมาก

สคริปต์จะดึงวันประกาศงบจาก Yahoo **เฉพาะหุ้นที่ติดสัญญาณ** (ไม่กี่สิบตัว ไม่ใช่ทั้ง 600 ตัว)
แล้วเก็บ cache ไว้ 3 วันเพื่อไม่ให้โดน rate limit

| โหมด | พฤติกรรม |
|---|---|
| `--earnings exclude` (ค่าเริ่มต้น) | **ตัดทิ้ง**ถ้างบจะออกภายใน 5 วัน |
| `--earnings flag` | เก็บไว้ทั้งหมด แต่ติดป้ายเตือนในคอลัมน์ "งบ" |
| `--earnings off` | ไม่เช็กเลย (เร็วที่สุด แต่ต้องเช็กเอง) |

หุ้นที่**เพิ่งประกาศงบไปเมื่อวาน**จะไม่โดนตัด แต่ติดป้าย `เพิ่งประกาศงบ` ไว้ —
เพราะบางคนตั้งใจเล่น post-earnings drift ซึ่งเป็นคนละเกมกับการถือข้ามวันงบ
ให้คุณตัดสินใจเอง

## ราคานอกเวลาทำการ (pre-market / after-hours)

รายงานคำนวณจากราคาปิดของวันทำการล่าสุด แต่ระหว่างที่คุณนอน ราคาอาจวิ่งไปไกลแล้ว
ถ้าหุ้นที่ติดสัญญาณซื้อร่วง 6% หลังตลาดปิด แผนเทรดทั้งแผนก็ใช้ไม่ได้แล้ว
คอลัมน์ **"นอกเวลา"** เอาราคาล่าสุดจริง ๆ มาเทียบให้

### ช่วงเวลาซื้อขายของตลาดสหรัฐ

| ช่วง | เวลานิวยอร์ก | เวลาไทย (ช่วง EDT) |
|---|---|---|
| Pre-market | 04:00–09:30 | 15:00–20:30 |
| เวลาทำการปกติ | 09:30–16:00 | 20:30–03:00 |
| After-hours | 16:00–20:00 | 03:00–07:00 |

### ป้ายสีในคอลัมน์

| สี | ความหมาย | ควรทำยังไง |
|---|---|---|
| 🔴 **แดง** — สวนทาง | ราคาวิ่งสวนกับทิศที่จะเทรด เกินเกณฑ์ | ข้ามตัวนั้นไป แผนเสียแล้ว |
| 🟡 **เหลือง** — วิ่งหนีไปแล้ว | วิ่งไปทางเดียวกับเราแต่แรงเกิน | เข้าที่ราคาเดิมไม่ได้ ไล่ราคาเสี่ยง |
| ⚪ **เทา** | ขยับน้อยกว่าเกณฑ์ | แผนในตารางยังใช้ได้ |

ด้านบนรายงานจะมีกล่องสรุปรวมว่ามีกี่ตัวที่ต้องคิดแผนใหม่ ไม่ต้องไล่หาเองทีละแถว

> ⚠️ **นอกเวลาทำการวอลุ่มบางมาก** ราคาขยับได้ด้วยไม้เล็ก ๆ ไม่กี่ไม้ และมักกลับทางตอนตลาดเปิดจริง
> ใช้เป็นสัญญาณเตือนว่า "ต้องกลับไปดูใหม่" ไม่ใช่ราคาที่จะได้จริง

### สแกนวันละ 2 รอบ

workflow ตั้งไว้ให้รันสองรอบ สัญญาณเหมือนกันทั้งสองรอบ (เพราะคำนวณจากราคาปิดชุดเดียวกัน)
ต่างกันที่ **ราคานอกเวลาที่เอามาเทียบ**

| รอบ | เวลา UTC | เวลาไทย | ได้ราคาช่วงไหน |
|---|---|---|---|
| เย็น | 22:30 | ~05:30 น. | after-hours — เห็นผลกระทบจากข่าวหลังตลาดปิด |
| ก่อนเปิดตลาด | 13:00 | ~20:00 น. | pre-market — สดที่สุดก่อนตลาดเปิดจริง |

รอบก่อนเปิดตลาดคือรอบที่ใช้ตัดสินใจจริง เพราะ gap ข้ามคืนเข้าไปในราคาแล้ว
รอบเย็นไว้ดูภาพรวมและเตรียมตัวล่วงหน้า

## ตัวกรองพื้นฐาน (ใช้กับทุกสัญญาณ)

ตัดหุ้นที่เทรดสั้นไม่ได้จริงออกก่อนเสมอ:

- ราคา $5–$2,000 — หุ้นต่ำกว่า $5 สเปรดกว้างและถูกปั่นง่าย
- มูลค่าซื้อขายเฉลี่ย 20 วัน ≥ 20 ล้านดอลลาร์ — เข้าออกได้โดยไม่ดันราคาตัวเอง
- ATR อยู่ระหว่าง 1.2%–15% ของราคา — แกว่งพอมีกำไร แต่ไม่บ้าคลั่ง

## คะแนน 0–100 หมายถึงอะไร

คะแนนบอกว่า **เข้าเงื่อนไขครบและแรงแค่ไหน** ไม่ได้บอกว่าจะกำไร
แต่ละสัญญาณให้น้ำหนักต่างกัน เช่น Breakout คิดจากแรงวอลุ่ม 25% + ความแรงเทรนด์ 25% +
โมเมนตัม 20 วัน 20% + ตำแหน่งปิดในแท่ง 15% + ความใกล้ high 52 สัปดาห์ 15%
แล้วหักคะแนนถ้าวิ่งมาไกลเกินไปแล้ว (ret20d > 40% หรือ RSI > 80)

หุ้นตัวเดียวอาจติดหลายสัญญาณพร้อมกันได้ (breakout แรง ๆ มักมาพร้อมวอลุ่มพุ่ง) — ถือเป็นสัญญาณที่หนักแน่นขึ้น

## จุดเข้า / ตัดขาดทุน / ขนาดไม้

- **จุดเข้า** = ราคาปิดล่าสุด (ใช้เป็นราคาอ้างอิง จริง ๆ ควรเข้าตามแผนของตัวเองในวันถัดไป)
- **ตัดขาดทุน** = 1.5 × ATR — ฝั่งซื้ออยู่**ใต้**ราคาปิด ฝั่งชอร์ตอยู่**เหนือ**ราคาปิด
  (Pullback ใช้ใต้ low 5 วัน / Rally Fade ใช้เหนือ high 5 วัน เผื่อ noise อีกครึ่ง ATR)
- **เป้าหมาย** = 3 × ATR ในทิศทางที่เทรด → อัตราส่วนกำไร:ขาดทุน 2:1 เท่ากันทั้งสองฝั่ง
- **ขนาดไม้** = คำนวณให้ขาดทุนไม่เกิน `--risk`% ของพอร์ตถ้าโดนตัดขาดทุน

ใช้ ATR แทน % คงที่เพราะหุ้นแต่ละตัวแกว่งไม่เท่ากัน — stop 3% ที่หลวมสำหรับ KO อาจแคบเกินไปสำหรับ NVDA

## สภาพตลาด (แถบบนสุดของรายงาน)

ก่อนดูรายชื่อหุ้น ให้ดูแถบนี้ก่อน — breakout ในตลาดที่ SPY อยู่ใต้ SMA200 ล้มเหลวบ่อยกว่ามาก

- **เทรนด์ SPY** — ขาขึ้น / ย่อ / อ่อนแอ
- **ตลาดเอื้อฝั่งไหน** — ฝั่งซื้อ / ฝั่งชอร์ต / ก้ำกึ่ง ใช้เลือกว่าวันนี้ควรเน้นตารางไหน
- **% หุ้นเหนือ EMA50 และ SMA200** — วัดความกว้างของตลาด ถ้าต่ำกว่า 40% แปลว่ามีไม่กี่ตัวที่ยังไปได้

ตลาดขาขึ้นแต่ไปเล่นสัญญาณชอร์ต (หรือกลับกัน) คือการสวนกระแสหลัก ทำได้แต่ควรลดขนาดไม้ลง

## ตั้งให้รันอัตโนมัติทุกวัน

### วิธีที่ 1 — GitHub Actions (แนะนำ: ฟรี ไม่ต้องเปิดคอมทิ้งไว้)

1. สร้าง repo ใหม่บน GitHub (ตั้งเป็น private ก็ได้) แล้วอัปโหลดโฟลเดอร์นี้ทั้งหมด
2. ไปที่ **Settings → Actions → General → Workflow permissions** เลือก **Read and write permissions**
3. (ถ้าอยากเปิดรายงานผ่านลิงก์เว็บ) **Settings → Pages → Source: GitHub Actions**
4. เสร็จแล้ว — จะรันเองทุกวันจันทร์–ศุกร์ **สองรอบ**: 22:30 UTC (~05:30 น. เช้าไทย)
   และ 13:00 UTC (~20:00 น. เย็นไทย ก่อนตลาดสหรัฐเปิด)
   กดรันเองได้ที่แท็บ **Actions → Daily Market Scan → Run workflow**

ผลลัพธ์จะถูก commit กลับเข้า repo ในโฟลเดอร์ `reports/` และเปิดดูได้ที่หน้า Pages ของ repo

## ทดสอบว่าสูตรถูกต้อง

```bash
python test_indicators.py   # เทียบ RSI/ATR/ADX/Bollinger กับค่าอ้างอิงมาตรฐานของ Wilder
python test_scanner.py      # ยิงหุ้นจำลอง 9 ตัวที่รู้คำตอบอยู่แล้วเข้าไปตรวจตรรกะทั้ง 6 สัญญาณ
python test_extended.py     # ตรวจการแยกช่วงเวลาซื้อขายและตรรกะเตือน gap
python test_e2e.py          # รันทั้งระบบด้วยข้อมูลจำลอง รวมทุกตัวกรอง ไม่แตะเน็ต
```

`test_scanner.py` ตรวจครบทั้ง: สัญญาณติดถูกตัว, **หุ้นขาขึ้นไม่ติดสัญญาณชอร์ตและกลับกัน**,
หุ้น sideways ไม่ติดอะไรเลย, ทิศของ stop/target ถูกด้านทั้งสองฝั่ง, ขนาดไม้ไม่เกินงบความเสี่ยง
และตรรกะ blackout ของวันงบทุกกรณีขอบ

## ปรับจูนเงื่อนไข

แก้ `CONFIG` ที่หัวไฟล์ `scanner.py` สำหรับตัวกรองพื้นฐานและการจัดการความเสี่ยง
ส่วนเงื่อนไขของแต่ละสัญญาณอยู่ในฟังก์ชัน `signal_breakout`, `signal_volspike`, `signal_pullback`,
`signal_breakdown`, `signal_distribution`, `signal_rallyfade`
ตัวเลขทุกตัวเขียนไว้ให้อ่านง่ายและแก้ได้ตรง ๆ

## ข้อจำกัดที่ต้องรู้

- **ข้อมูลจาก Yahoo Finance ฟรี** — ปรับปรุงหลังตลาดปิด บางครั้งมีค่าผิดพลาดหรือขาดหาย และมี rate limit ถ้ายิงถี่เกินไป
- **วันประกาศงบพึ่ง Yahoo** — บางครั้งไม่อัปเดตหรือไม่มีข้อมูล (จะขึ้นว่า `ไม่ทราบวันงบ`)
  ETF ไม่มีวันงบอยู่แล้ว · ยังไม่กรองข่าวอื่น เช่น ผลทดลองยา คดีความ หรือดีล M&A
- **ไม่มีผล backtest ในสคริปต์นี้** — เงื่อนไขทั้งหมดตั้งจากหลักการที่ใช้กันทั่วไป ไม่ใช่ค่าที่ผ่านการ optimize
  ควรจดผลย้อนหลังเองหรือเทรดกระดาษก่อนอย่างน้อย 1–2 เดือน
- **ไม่เช็กสถานะการยืมหุ้นสำหรับชอร์ต** — สัญญาณชอร์ตบางตัวอาจชอร์ตไม่ได้จริงในโบรกเกอร์ของคุณ
- **ราคานอกเวลาทำการเชื่อถือได้จำกัด** — วอลุ่มบาง ข้อมูลจาก Yahoo ไม่ครบทุกตัว
  และราคามักกลับทางตอนตลาดเปิดจริง เป็นสัญญาณเตือน ไม่ใช่ราคาที่จะได้
- **ไม่รวมค่าคอมมิชชัน สเปรด และ slippage** ในการคำนวณเป้าหมาย

การเทรดสั้นมีความเสี่ยงสูงและผู้เทรดรายย่อยส่วนใหญ่ขาดทุน ใช้เงินที่รับความเสี่ยงได้เท่านั้น
